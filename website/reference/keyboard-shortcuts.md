# Keyboard shortcuts

Every command, with or without a shortcut, is also in the [command palette](/guide/command-palette) (<kbd>⇧⌘P</kbd>).

## The essentials

| Action | Shortcut |
| --- | --- |
| Command palette | <kbd>⇧⌘P</kbd> |
| Go to a channel or conversation | <kbd>⌘P</kbd> or <kbd>⌘K</kbd> |
| Select Theme… (live preview) | <kbd>⌃⌘T</kbd> |
| Focus the message box | <kbd>⌘L</kbd> |
| Settings | <kbd>⌘,</kbd> |

## Moving around

| Action | Shortcut |
| --- | --- |
| Previous tab of this network: its console, channels and conversations, wrapping around at the ends (the same list in the sidebar) | <kbd>⇧⌘[</kbd> or <kbd>⌃⇧Tab</kbd> |
| Next tab of this network | <kbd>⇧⌘]</kbd> or <kbd>⌃Tab</kbd> |
| Previous network, on the channel or conversation you were last on there | <kbd>⌃⌘[</kbd> |
| Next network | <kbd>⌃⌘]</kbd> |
| Previous conversation, across every network | <kbd>⌥⌘↑</kbd> |
| Next conversation, across every network | <kbd>⌥⌘↓</kbd> |
| Previous conversation with unread messages | <kbd>⌥⇧⌘↑</kbd> |
| Next conversation with unread messages | <kbd>⌥⇧⌘↓</kbd> |
| Channel or conversation 1–9 of the current network, in tab order (the console has no number) | <kbd>⌘1</kbd> … <kbd>⌘9</kbd> |
| Focus the sidebar, or the tabs (**Go → Focus Sidebar** or **Focus Tabs**) | <kbd>⌥⌘1</kbd> |
| Focus the messages | <kbd>⌥⌘2</kbd> |
| Focus the message box | <kbd>⌥⌘3</kbd> or <kbd>⌘L</kbd> |
| Focus the member list, showing it first if it's hidden | <kbd>⌥⌘4</kbd> |
| Next / previous area: the sidebar or tabs, the messages, the message box and the member list, in turn | <kbd>F6</kbd> / <kbd>⇧F6</kbd> |

## The sidebar

With the sidebar or the rail focused (<kbd>⌥⌘1</kbd>). The selected row has a ring in your theme's focus color.

| Action | Shortcut |
| --- | --- |
| Select the network, channel or conversation above or below | <kbd>↑</kbd> <kbd>↓</kbd> |
| Select the first or the last | <kbd>Home</kbd> <kbd>End</kbd> |
| From a channel or conversation, go to its network | <kbd>←</kbd> |
| Fold a network's channels away, or show them again | <kbd>←</kbd> / <kbd>→</kbd> on the network |
| Go to a network, channel or conversation by name | type its first letters |
| Back to the message box | <kbd>Return</kbd> or <kbd>Esc</kbd> |

Clicking a channel still takes you to its message box, as always.

## Tabs

With the tabs focused (<kbd>⌥⌘1</kbd>). The selected tab has a ring in your theme's focus color.

| Action | Shortcut |
| --- | --- |
| Select the tab to the left or right | <kbd>←</kbd> <kbd>→</kbd> |
| Select the first or the last tab of the row | <kbd>Home</kbd> <kbd>End</kbd> |
| Go between the network row and the channel row | <kbd>↑</kbd> <kbd>↓</kbd> |
| Back to the message box | <kbd>Return</kbd> or <kbd>Esc</kbd> |

These also work when you reach a tab with <kbd>Tab</kbd>, with **Keyboard navigation** on in **System Settings → Keyboard**.

## The member list

With the member list focused (<kbd>⌥⌘4</kbd>). The highlighted person has a ring in your theme's focus color.

| Action | Shortcut |
| --- | --- |
| Move the highlight | <kbd>↑</kbd> <kbd>↓</kbd> |
| Move a page at a time | <kbd>Page Up</kbd> <kbd>Page Down</kbd> |
| Go to the first or the last person | <kbd>Home</kbd> <kbd>End</kbd> |
| Open a private conversation with them | <kbd>Return</kbd> |
| Open their [user menu](/guide/user-menu) | <kbd>Space</kbd> or <kbd>⇧F10</kbd> |
| Filter the list | type a name |
| From the filter, back to the list | <kbd>↓</kbd> |
| Clear the filter, then go back to the message box | <kbd>Esc</kbd> |

## The emoji picker {#emoji-and-gifs}

Press <kbd>⇧⌘E</kbd>, or click the smiley in the message field, to open the [emoji picker](/guide/emoji-and-gifs). Its search field has the keyboard.

| Action | Shortcut |
| --- | --- |
| Move through the emoji | <kbd>↑</kbd> <kbd>↓</kbd> <kbd>←</kbd> <kbd>→</kbd> |
| Pick the selected one (while searching with nothing selected, the first emoji found) | <kbd>Return</kbd> |
| Close, back to the message field | <kbd>Esc</kbd> |

GIF search joins the picker in a later version (it's only in development builds for now). With it, <kbd>Tab</kbd> or <kbd>⌃Tab</kbd> switches between **Emoji** and **GIFs**, <kbd>Return</kbd> sends a GIF search without waiting, and <kbd>Delete</kbd> at the start of the message removes the GIF you picked.

## The messages

Press <kbd>⌥⌘2</kbd> (**Go → Focus Messages**), or <kbd>F6</kbd> until you get there, to pick a message with the keyboard. The newest message is selected, or the lowest one in view if you've scrolled up. Joins, parts and other events are skipped; a collapsed run of joins and parts can be selected.

| Action | Shortcut |
| --- | --- |
| Previous / next message | <kbd>↑</kbd> / <kbd>↓</kbd> |
| A page of messages up / down | <kbd>Page Up</kbd> / <kbd>Page Down</kbd> |
| The first / last message loaded | <kbd>Home</kbd> / <kbd>End</kbd> |
| Reply (on servers without IRCv3 replies, start a message with `nick: `) | <kbd>R</kbd> |
| React (opens the emoji picker; the arrows and <kbd>Return</kbd> pick) | <kbd>E</kbd> |
| Copy the text | <kbd>C</kbd> or <kbd>⌘C</kbd> |
| Open the link (a menu of them when there are several) | <kbd>Return</kbd> |
| Show or hide the joins and parts in a collapsed run | <kbd>Return</kbd> |
| The sender's menu: message, mention, whois, op… | <kbd>U</kbd> |
| Translate, or hide the translation | <kbd>T</kbd> |
| Every action for the message (its right-click menu) | <kbd>Space</kbd>, <kbd>⇧F10</kbd> or the context-menu key |
| Back to the message field | <kbd>Esc</kbd> |

Typing anything else goes back to the message field and types it there.

## Standard macOS shortcuts

The usual ones work as you'd expect: <kbd>⌘Q</kbd> quits, <kbd>⌘H</kbd> hides Vela, <kbd>⌘M</kbd> minimizes the window, and <kbd>⌘C</kbd> / <kbd>⌘V</kbd> copy and paste. As in a browser, <kbd>⌘W</kbd> closes the tab in the main window and <kbd>⇧⌘W</kbd> closes the window; in other windows, such as Settings, <kbd>⌘W</kbd> closes the window.
