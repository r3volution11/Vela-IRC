# Keyboard shortcuts

Every command, with or without a shortcut, is also in the [command palette](/guide/command-palette) (<kbd>⇧⌘P</kbd>).

## The essentials

| Action | Shortcut |
| --- | --- |
| Command palette | <kbd>⇧⌘P</kbd> |
| Go to a channel or conversation | <kbd>⌘P</kbd> or <kbd>⌘K</kbd> |
| Select Theme… (live preview) | <kbd>⌃⌘T</kbd> |
| Focus the message field | <kbd>⌘L</kbd> |
| Settings | <kbd>⌘,</kbd> |

## Moving around

| Action | Shortcut |
| --- | --- |
| Previous conversation | <kbd>⌥⌘↑</kbd> |
| Next conversation | <kbd>⌥⌘↓</kbd> |
| Previous conversation with unread messages | <kbd>⌥⇧⌘↑</kbd> |
| Next conversation with unread messages | <kbd>⌥⇧⌘↓</kbd> |
| Channel or conversation 1–9 of the current network, in tab order (tab stacks) | <kbd>⌘1</kbd> … <kbd>⌘9</kbd> |
| Move between tabs, when a tab row has keyboard focus | <kbd>←</kbd> <kbd>→</kbd> <kbd>Home</kbd> <kbd>End</kbd> |

## View

| Action | Shortcut |
| --- | --- |
| Collapse or expand the sidebar | <kbd>⌃⌘S</kbd> |
| Show or hide the member list | <kbd>⇧⌘M</kbd> |
| Bigger text | <kbd>⌘+</kbd> |
| Smaller text | <kbd>⌘−</kbd> |
| Actual size | <kbd>⌘0</kbd> |

## Networks and channels

| Action | Shortcut |
| --- | --- |
| Add Network… | <kbd>⇧⌘N</kbd> |
| Join Channel… | <kbd>⌘J</kbd> |
| Reopen the channel you removed or the conversation you closed last (again to go further back) | <kbd>⇧⌘T</kbd> |
| Undo leaving, removing or closing, right after (Edit → Undo) | <kbd>⌘Z</kbd> |
| Redo it | <kbd>⇧⌘Z</kbd> |
| Cancel dragging a network, channel or tab (it goes back where it was) | <kbd>Esc</kbd> |

## The message field

| Action | Shortcut |
| --- | --- |
| Send | <kbd>Return</kbd> |
| New line | <kbd>⇧Return</kbd> or <kbd>⌥Return</kbd> |
| Complete a nick, `#channel`, `/command` or `:emoji:` (again for the next match) | <kbd>Tab</kbd> |
| Previous / next message you sent in this channel | <kbd>↑</kbd> / <kbd>↓</kbd> |
| Cancel a reply or a pending multi-line paste | <kbd>Esc</kbd> |
| Undo typing (and, after it, leaving or closing a channel) | <kbd>⌘Z</kbd> |
| Emoji & Symbols (macOS) | <kbd>⌃⌘Space</kbd> |
| Show Spelling and Grammar | <kbd>⌘:</kbd> |
| Check Document Now (check the message's spelling) | <kbd>⌘;</kbd> |

## In the palette

| Action | Shortcut |
| --- | --- |
| Move the highlight | <kbd>↑</kbd> <kbd>↓</kbd> or <kbd>⌃P</kbd> <kbd>⌃N</kbd> |
| Move a page at a time | <kbd>Page Up</kbd> <kbd>Page Down</kbd> |
| Choose | <kbd>Return</kbd> |
| Close (and, in Select Theme, go back to your theme) | <kbd>Esc</kbd> |
| Switch from conversations to commands | type <kbd>></kbd> |
| Switch back to conversations | <kbd>Backspace</kbd> in the empty field |

## The settings editor

In **Settings → Advanced**. See [Settings editor](/customize/settings-editor).

| Action | Shortcut |
| --- | --- |
| Search settings (UI view) | <kbd>⌘F</kbd> |
| Clear the search | <kbd>Esc</kbd> |
| Save settings.json (JSON view) | <kbd>⌘S</kbd> |
| Find / find and replace (JSON view) | <kbd>⌘F</kbd> / <kbd>⌥⌘F</kbd> |
| Next / previous match | <kbd>⌘G</kbd> / <kbd>⇧⌘G</kbd> |
| Find the selected text | <kbd>⌘E</kbd> |
| Show suggestions | <kbd>⌃Space</kbd>, <kbd>⌥Esc</kbd> or <kbd>F5</kbd> |
| Indent / outdent | <kbd>Tab</kbd> / <kbd>⇧Tab</kbd> |

## Images and the theme editor

| Action | Shortcut |
| --- | --- |
| Copy the image (image viewer) | <kbd>⌘C</kbd> |
| Close the image viewer | <kbd>Esc</kbd> |
| Save the theme (theme editor) | <kbd>⌘S</kbd> |
| Close the theme editor | <kbd>⌘W</kbd> |

## Standard macOS shortcuts

The usual ones work as you'd expect: <kbd>⌘Q</kbd> quits, <kbd>⌘H</kbd> hides Vela, <kbd>⌘M</kbd> minimizes the window, and <kbd>⌘C</kbd> / <kbd>⌘V</kbd> copy and paste.
